# Neural Network Chatbot (Python)

An intent-based gaming information chatbot built from scratch using **Python**, **NLTK**, and **TensorFlow**.  
This project focuses on understanding core NLP concepts without relying on external AI APIs.

---

## 📌 Project Overview

This chatbot is designed to answer **gaming-related questions**, such as:
- Game genres and types
- Popular games
- Gaming platforms (PC, console, mobile)
- FPS, RPG, multiplayer, and single-player games
- Basic conversational intents (greeting, thanks, goodbye)

The chatbot uses **Natural Language Processing (NLP)** techniques and a **neural network classifier** to identify user intent and respond accordingly.

---

## ⚙️ How It Works

1. User input is tokenized and lemmatized using **NLTK**
2. A **Bag-of-Words** model converts text into numerical features
3. A **Neural Network (Keras / TensorFlow)** predicts the intent
4. A random response is selected from the matched intent
